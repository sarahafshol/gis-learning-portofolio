# Project 01: Basic Mapping & Spatial Data Visualization

## Overview
This project explores the fundamentals of Geographic Information Systems (GIS) through basic mapping and spatial data visualization of Bekasi City, West Java, Indonesia.

The map visualizes the city's administrative boundary and road network using QGIS and OpenStreetMap data.

## Objectives
- Practice loading and managing spatial datasets in QGIS.
- Visualize administrative boundaries and road networks.
- Learn basic cartographic design and map layout preparation.
- Produce a map suitable for geographic visualization and portfolio presentation.

## Tools
- QGIS
- OpenStreetMap
- QuickOSM plugin

## Data Sources
- OpenStreetMap contributors — basemap and road network data.
- Administrative boundary dataset — source to be documented with the original dataset provider.

## Outputs
- `bekasi_basic_map.png` — exported map image.
- `bekasi_basic_map.pdf` — printable map.
- QGIS project file (`.qgz`) — editable project, if included.

## Key Learning Outcomes
- Loading and styling spatial vector data.
- Working with road network data.
- Managing map layers and symbology.
- Creating a print layout with a title, legend, north arrow, and scale bar.
- Exporting maps for documentation and presentation.

## Notes
This is a beginner learning project focused on GIS fundamentals and cartographic visualization. It does not represent a comprehensive road network analysis.
